# ⚡ SDR Intelligence Engine

An automated AI-driven dashboard designed for Sales Development Representatives (SDRs) to streamline post-call workflows and improve conversion rates.

## 🚀 Overview
The SDR Intelligence Engine leverages the **Gemini 3.5 Flash** model to transform unstructured sales call transcripts into actionable data instantly. By automating the extraction of key insights, this tool helps SDRs reduce administrative overhead and focus on high-impact follow-ups.

## 🔑 Key Features
* **Automated Objection Analysis**: Instantly identify client pain points (e.g., budget, bandwidth, competition).
* **CRM-Ready Summaries**: Generate standardized, professional summaries for Salesforce or HubSpot.
* **Smart Follow-Ups**: Draft hyper-personalized, high-converting follow-up emails based on specific call details.
* **High-Speed Processing**: Optimized with a low-temperature, high-speed configuration for near-instant insights.
* **Resilient Architecture**: Built-in exponential backoff retry logic to handle API rate limits and server spikes gracefully.

## 🛠 Tech Stack
* **Frontend**: Streamlit
* **AI Engine**: Google Gemini API (Gemini 3.5 Flash)
* **Language**: Python
